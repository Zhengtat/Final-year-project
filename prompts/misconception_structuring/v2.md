You are reading one passage of a computer-networking textbook to find out whether the BOOK ITSELF
warns against a wrong belief: it states the belief (or says readers might hold it), rejects it, and
gives the correct idea. Ordinary facts that happen to use "not" are NOT warnings.

Set is_warning to true ONLY if the passage describes a belief that is wrong AND rejects it. A plain
negated fact ("a switch does not forward by IP address"), a scope note ("this implementation does
not support X") or study advice ("it is tempting to skip the details") is is_warning = false. If
is_warning is false, fill reason and set every other field to null, an empty list, or "none" for
prevalence_cue.

If is_warning is true, write the WRONG belief as one edge between two expert nodes shown below
(use node ids exactly as listed):
- wrong_relation: one of the relations below, or conflated_with when the belief is that two
  different things are the same.
- wrong_polarity: "affirmed" if the belief asserts the relation, "negated" if it denies it.
- perturbation_type, relative to the correct edge it contradicts:
  polarity_flip (same edge, opposite truth); reversed (same relation, endpoints swapped);
  substituted_concept (same relation, one endpoint swapped for a different node); conflation
  (two different things believed to be one); wrong_category (is_a to the wrong kind);
  wrong_relation (same two nodes, a different relation); condition_error (right edge, wrong
  conditions); modality_error (right edge, wrong strength: always vs typically, and so on).
- contradicts: the ids of the listed EXPERT EDGES (ids starting E:) that state the correct idea (at
  least one). For a conflation, the id of a listed LOOK-ALIKE entry (starting L:) for the same two
  nodes also works: it records that the book keeps the two things apart. If the
  correct idea is stated in the passage but no listed edge says it, leave contradicts empty and fill
  the proposed correct edge fields (proposed_correct = true) instead.
- intuition: the wrong belief in one plain sentence, as the book states it.
- misconception_quote and correction_quote: EXACT substrings of the passage (copy
  character-for-character); they may be the same sentence.
- prevalence_cue: stated_common if the book says it is a common mistake or misconception;
  stated_possible if it says one might think or expect it; otherwise none.
- wrong_modality and wrong_conditions describe the belief's strength and conditions (needed to check
  modality_error and condition_error; otherwise null and an empty list).
