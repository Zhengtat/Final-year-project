You are drafting an expert knowledge-graph fragment for one exam question, to be
reviewed and corrected by a human before it becomes gold-standard data. Every
concept, edge and chain link you propose must be traceable to the textbook
section(s) below.

Question:
{question}

Reference (model) answer:
{reference_answer}

Textbook section(s) covering this question:
{sections_block}

Relation guideline (definitions, templates, examples, and what NOT to confuse each
relation with — choose the closest match; use "other" only if truly nothing fits):
{relation_guideline}

Task:

1. **Concepts.** List the distinct concepts (protocols, mechanisms, components,
   parameters, properties, events, states) that the reference answer and the
   sections rely on. For each: canonical_name, node_type (Protocol, Mechanism,
   Component, DataUnit, Parameter, Property, Event, State, Layer, or Concept), a
   short definition in the book's own words, and an evidence_quote — an EXACT
   quote from the section text above (copy character-for-character, no ellipses).

2. **Edges.** List the edges between those concepts that the reference answer
   needs. For each: source_concept_name/target_concept_name (must exactly match a
   canonical_name from step 1), relation (from the guideline above), polarity
   (affirmed/negated), modality (necessary/always/typically/possible/never),
   conditions, a one-sentence statement, criticality (core/supporting/peripheral),
   an evidence_quote (EXACT substring), chain_id + chain_position if this edge is
   one step in a multi-step process (else null for both), and:
   - **part_type**: required when relation is "part_of" — one of component
     (field/module of a structured whole), member (element of a collection/group),
     phase (step/stage of a process). null for every other relation.
   - **dimension**: only when relation is "contrasts_with" — name what differs
     (e.g. "cwnd growth rate", "clock recovery"). null otherwise.
   - **surface_phrase**: the linking words as they actually appear in the section
     text (e.g. "is used to", "doubles", "is part of") — always required.

3. **Chain links.** Where the reference answer connects two of your edges with a
   reason (because / in order to / if...then / then / whereas), propose a chain
   link: from_edge_index and to_edge_index are 0-based positions in the `edges`
   list above (from_edge_index is the edge that is SUPPORTED, to_edge_index is the
   edge that SUPPORTS it — e.g. "cwnd resets BECAUSE a timeout occurred": from =
   the cwnd-reset edge, to = the timeout edge), a type (cause/purpose/condition/
   sequence/contrast), a one-sentence statement, the surface_phrase connective as
   written (or null if you inferred the link without an explicit connective), and
   an evidence_quote (EXACT substring covering the reasoning, e.g. the sentence
   containing "because"). Only propose a chain link when the text actually
   connects the two propositions — don't invent connections between unrelated edges.

Every evidence_quote must be copied character-for-character from the section text
above.
