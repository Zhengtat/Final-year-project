You are drafting an expert knowledge-graph fragment for one exam question, to be
reviewed and corrected by a human before it becomes gold-standard data. Every
concept and edge you propose must be traceable to the textbook section(s) below.

Question:
{question}

Reference (model) answer:
{reference_answer}

Textbook section(s) covering this question:
{sections_block}

Relation vocabulary you must use (do not invent new relation names):
{relation_vocab}

Task:
1. List the distinct concepts (protocols, mechanisms, components, parameters,
   properties, events, states) that the reference answer and the sections rely on.
   For each: a canonical_name, its node_type (one of Protocol, Mechanism,
   Component, DataUnit, Parameter, Property, Event, State, Layer, Concept), a
   short definition in the book's own words, and an evidence_quote — an EXACT
   quote from the section text above that supports this concept existing (do not
   paraphrase; copy the exact wording).
2. List the edges (relations) between those concepts that the reference answer
   needs. For each: source_concept_name and target_concept_name (must exactly
   match a canonical_name from step 1), relation (from the vocabulary above),
   polarity (affirmed/negated), modality (necessary/always/typically/possible/
   never), conditions (a list of other concept names this edge only holds under,
   or an empty list), a one-sentence statement, criticality (core/supporting/
   peripheral — core means the reference answer cannot be right without it), an
   evidence_quote (EXACT substring from the section text), and optionally a
   chain_id + chain_position if this edge is one step in a multi-step process
   described in the reference answer (e.g. phases of an algorithm), else null
   for both.

Every evidence_quote must be copied character-for-character from the section
text above — do not summarize, do not fix typos, do not add ellipses.
