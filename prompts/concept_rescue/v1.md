You are reviewing one section of a {domain} textbook. A first reader already listed the concepts it found. A
program then proposed CANDIDATE terms that the first reader did not record. They are only hints: most are not
concepts. Decide, for every candidate, exactly one outcome.

Definitions (the same as for the first reader):
- A concept is a single word or short phrase naming an essential knowledge element of the domain, with a
  specific meaning in the field. A word that is also an everyday word IS a concept when the field gives it a
  specific technical meaning.
- Not concepts: generic discourse words ("approach", "case", "example", "issue", "way"), descriptive phrases,
  clauses, lists, and specific values (numbers, sizes, rates, dates).
- Use the whole term as the text names it. If the candidate is only part of a longer term the text uses,
  reject it (reason inside_longer_term) unless the text also uses it on its own as a concept.
- Keep a device or component and the process it performs as separate concepts.

Outcomes:
- add_new: the candidate is a concept the text names and it is NOT among the EXISTING NODES. Give name, aliases,
  node_type, role ("defined" only when this section states what it is; otherwise "used" or "mentioned"),
  evidence (an EXACT substring of the section text, copied character for character, that contains the name),
  and para (the paragraph label).
- link_existing: the candidate is the same concept as an EXISTING NODE (interchangeable in any sentence of the
  book; a kind, part, instance, version or predecessor is NOT the same). Give node_id, surface (as written in
  the text), node_type, role, evidence (exact substring containing the surface) and para.
- reject: anything else. Give a short reason.

Rules:
- Return exactly one decision per candidate, in the same order, with the candidate_id.
- Fields that do not apply to the outcome are null (name, node_type, role, evidence, para, node_id, surface) or
  an empty list (aliases).
- Node types: Protocol, Mechanism, Component, DataUnit, Parameter, Property, Event, State, Layer, Identifier, Concept.
- When unsure, reject.
