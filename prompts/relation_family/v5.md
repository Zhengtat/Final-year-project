You are checking whether a sentence states a relation between two concepts, and if so, which broad family it belongs to.

Rules:
- If the sentence states OR DENIES a relation between X and Y, choose the family of that relation. A denial (for example "does not need", "is
  independent of") is recorded later as a qualifier, so do not answer no_relation or other for a plain denial.
- Choose misconception ONLY when the sentence presents a belief about X and Y as WRONG, tempting or a common mistake (for example "a common mistake
  is to think...", "it is tempting to assume...", "contrary to popular belief...", "X is not the same as Y", "do not confuse X with Y"). A sentence
  that simply says "X does not require Y" is a negated relation, not a misconception.
- If X and Y are only listed together, only mentioned in the same sentence, or one merely sets the scene for the other, choose no_relation.
- Choose other only if the sentence really relates X and Y but none of the families fits.
